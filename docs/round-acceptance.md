# 本轮验收清单

状态按代码和模拟器 CI 为准。功能绿在 `4e1626c`，运行 https://github.com/harrisliangsu/little-baby-log/actions/runs/45131874370 。版本改为 1.1.5 (7)，不复用 1.1.4 (6)。iCloud 仍未初始化。真实接口、真麦克风、真备份、真机桌面小组件没有在这台机器验证。

1. 奶粉冲好总奶量 65/100/130/170/200。模拟器里输入 120 后卡片出现该毫升数。保存按钮在字段下方，高度 56 点。真机键盘遮挡没有另拍。
2. 原生 Chat：气泡、复制、停止和重试已接上。DeepSeek 网页 demo 不嵌入，Key 不发给 demo 站。真实接口尚未在这台机器调用。
3. 长按半屏录音、确认后才进入 Chat：已接上。真麦克风未在这台机器验证。
4. 底栏含四个原标签和中间语音：已接上。测试从底栏按钮进入。
5. 外观只剩跟随系统、浅色、深色，并立刻写窗口样式。风格独立为经典或液态玻璃：经典是系统分组实色，液态玻璃用系统玻璃，减少透明度或旧系统用材质。默认经典。
6. 设置按宝宝与记录、外观、AI、通知、小组件、数据与同步、语言、关于分组。
7. 供应商是多张卡片。旧 Key 按供应商迁到各自的配置 ID。删除当前配置不会自动改用另一张。保存不等于验证。
8. 配置用弹窗。左右滑可以设为当前或编辑，删除要再确认，不能一口气滑掉。
9. 小组件按列均分标题、时间和数量，时间用完整的短格式。真机 SpringBoard 还没截图。
10. 新的小便保存会写一条带关联 ID 的换尿布。再次保存不重复。旧小便编辑不补造。单独换尿布不写小便。导入路径没有调用这个关联。
11. 奶粉等大卡和主历史可编辑。辅食、吸奶、生长、用药在其他记录下有「记录」入口，打开同一张表单。
12. 辅食可以有多项食物和勺数，水是整条记录共用的毫升。旧的食物名不会被当成勺。表单已接上。
13. 新建记录按类型决定沿用什么。奶粉只沿用冲好总奶量表里的上次量。辅食沿用上次食物、勺和共用水量。用药只沿用药名。睡眠、生长、吸奶、亲喂时长和备注重新开始。时间用现在。
14. 设置里点宝宝行即按 babyID 切换。编辑是旁边的按钮。
15. 生日、可选时刻、时区、性别和本地头像在宝宝表单里。农历、生肖、星座、八字用 lunar-swift 1.1.9 现算。没填时刻就不显示时柱。
16. 照顾者关系：已提交。本地一个照顾者 ID 加宝宝 ID，不改变邀请或权限。
17. 导入按已确认的字段名，不再猜 time 或 start。奶粉用 formulaFedTime。小便用 urineTime。睡眠用小写 starttime。身高体重只有日期，预览写明没有时刻。自定义记录的 valueName 即使像毫秒也不当时间。删除快照不导入。同名宝宝按 hashid 分开。测试全是虚构值。
18. 今天、历史和小组件用同一套 Phosphor 线标。大便和换尿布用自己的线标。暂停、醒来仍用系统符号，因为那是动作不是记录类型。真机桌面还没截图。历法使用 lunar-swift 1.1.9（MIT，ThirdParty/lunar-swift-LICENSE）。年柱对过该库公开用例 2024-02-05 08:00 为甲辰、丙寅。生肖按春节，月柱按节气而不是中气。
